Interview Essay · Game Analysis

「选一个游戏，讲核心玩法、优劣与设计」满分答案

以《杀戮尖塔》与《明日方舟：终末地》为例，逐段标注评分点。 重点不在范文本身，而在「每一段为什么这样写就能拿分」。

两份完整答案 五段评分点拆解 可套用骨架

00先看评分逻辑：阅卷人在找什么

这道题没有标准答案，但有明确的评分维度。理解这一点比背范文重要——因为阅卷人就是在用这套结构找东西，你只要把五个位置都填上，分数就不会低。

段落评分点在找什么分值权重常见失分写法
① 定位能否用一句话说清「这是什么、给谁玩、核心体验是什么」1–2 分绝大多数人跳过，直接开始吹玩法
② 核心循环能否拆成「行动→反馈→成长→再行动」的闭环，而不是罗列功能3 分写成功能清单（有卡牌、有遗物、有商店）
③ 优点是否具体到机制，能否说出「为什么这个设计有效」3 分写「玩法丰富、美术精美」
④ 缺点是否敢批、批得准，且区分「设计问题」与「资源问题」3 分只夸不批，或批「优化不好」
⑤ 你的设计是否有可执行的方案 + 可验证的指标4 分写「增加更多内容」「优化平衡性」
这道题真正的分水岭在第五段
前四段（定位、循环、优劣）只要认真玩过都能写出来，属于及格线。真正拉开差距的是「你会怎么设计」——它考的是你能否从玩家视角切换到开发者视角：发现问题 → 提出方案 → 定义如何验证 → 承认副作用。四步齐全才是满分，只提方案不提验证，最多给一半。
两条硬性纪律
① 只讲一个游戏。题目说「选一个」，讲两个会显得没有深度，而且时间不够展开，两道都写只会变成两份浅尝辄止的评测。② 只讲你真玩过的。第五段要给出具体机制和数值感受，没玩过的人写不出具体机制，卷面上一眼就能看出来。

01答案 A：杀戮尖塔（推荐）

推荐理由：机制清晰、可拆解、单机无运营干扰，最容易写出「设计感」而不是「体验感」。而且它是卡牌构筑品类的定义者，阅卷人大概率玩过，容易共鸣。

题目：选一个你熟悉的游戏，说明核心玩法、优劣，以及你会怎么设计。

① 定位

我选《杀戮尖塔》（Slay the Spire），Mega Crit 开发的单机卡牌构筑 Roguelike。它面向的是「愿意在碎片时间里做高密度决策」的核心向玩家，核心体验可以概括为一句话：用有限的信息做出最优的资源交换，并承担交换的后果。

评分点：品类 + 厂商 + 目标用户 + 一句话核心体验。「资源交换」这个提法直接为后文的优缺点埋下伏笔。

② 核心玩法：一个闭环，不是一堆功能

它的循环是四段咬合的：

  • 行动：在地图分支上选节点（普通战斗 / 精英 / 事件 / 商店 / 篝火），进入回合制战斗，每回合 3 点能量，打出攻击、技能、能力三类牌。
  • 反馈：敌人下回合的行动意图完全可见——打多少、防御多少、上什么负面状态，全部提前显示。玩家据此决定「这回合进攻还是防守」。
  • 成长：战斗后从三张牌中选一张加入卡组，加上遗物、药水，形成三条独立的构筑线。卡组越精简、遗物与卡牌越协同，强度越高。
  • 再行动：卡组成型后挑战精英与 Boss，通关三层，失败则重开，用 Ascension（进阶）层级叠加难度。

所以它本质上是「资源管理 + 构筑检验」的双层结构：地图层管路线与资源分配，战斗层管构筑是否成立。

评分点：拆成闭环而不是罗列「有卡牌、有遗物、有商店」。最后一句「双层结构」是加分项，说明你不只是玩家，还在看系统分层。

③ 优点：说清「为什么这个设计有效」

第一，意图可见把随机性从「战斗中」压缩到了「战斗前」。这是它区别于绝大多数 Roguelike 的关键。多数同类游戏的随机性作用在结果上，玩家输了只能归因为运气；而杀戮尖塔把随机性前置到「你抽到什么牌、走哪条路」，战斗过程本身是完全确定的博弈。结果是：玩家失败时能明确知道「我第三回合该防没防」，惩罚因此变成了可归因的决策错误，而不是运气不好。这直接决定了它的学习曲线是「可进步的」，而不是「可抱怨的」。

第二，单局时长与构筑深度匹配得刚好。一局通常在 40 到 90 分钟，恰好够走完「白板卡组 → 流派成型 → 接受检验」的完整弧线。对比很多 Roguelike 单局两小时以上，它的开局成本低得多——这意味着玩家愿意反复试错，而反复试错正是构筑类游戏乐趣的来源。

评分点：每条优点都给了「机制 → 玩家心理 → 结果」的因果链，而不是形容词。第一条还做了一个横向对比（多数 Roguelike），体现品类认知。

④ 缺点：区分设计问题与资源问题

第一，高难度下流派收敛，策略空间被压缩。这是设计层面的问题。表面上有几百张牌，但在高 Ascension 层级，能稳定通关的构筑路线会大幅收窄——玩家的最优解逐渐变成「抓这几张关键牌、跳过其他」。也就是说，难度提升没有带来「新策略」，只是淘汰了「旧策略」。对核心玩家而言，这会让后期的重复游玩从「探索」退化为「执行」。

第二，表现层资源复用度高，长线新鲜感衰减快。这是资源层面的问题，需要和上一条区分开：敌人种类、场景、动画表现都相对克制，玩到几十小时后，视觉与叙事层面的新刺激基本耗尽，剩下的驱动力只有「数值挑战」。对买断制独立游戏而言这是合理取舍，但它确实限制了「非硬核玩家」的留存。

评分点：这是最容易拿分也最容易丢分的一段。关键动作是明确区分「设计问题」与「资源问题」——前者能靠改机制解决，后者只能靠加预算解决。能做出这个区分，说明你理解开发约束。

⑤ 我会怎么设计

我会保留「意图可见 + 构筑检验」这个核心不动，只针对「高难度流派收敛」做一处改动：

方案：把 Ascension 的难度修饰符，从「纯数值加压」改为「结构性约束」。具体做法是——在高 Ascension 层级，每局开始时随机封禁 1 到 2 个流派的核心组件（例如本局不出现某张关键能力牌，或某个遗物不进入掉落池），并在开局明确告知玩家「本局禁用清单」。这样玩家每局都必须重新规划构筑路线，而不是背一套最优解执行到底。

为什么这样做：难度应该改变「你该做什么」，而不是只改变「你得多强」。禁选把「随机性」重新注入了决策层，同时因为开局就公开禁用清单，它依然是「信息透明」的——不违背游戏的核心设计原则。

怎么验证有效（三个指标）：

  1. 流派分布均匀度：统计高 Ascension 下各流派通关占比，看是否从「集中在两三个流派」变成更分散。这是方案是否生效的直接判据。
  2. 单局卡组多样性：统计通关卡组的构成差异度（同一流派内部的卡牌组合是否也在变化），防止玩家只是「换了个流派继续背最优解」。
  3. 高 Ascension 玩家的开局次数与留存：这是反向指标——如果多样性上去了但玩家不玩了，说明改动伤害了体验，方案失败。

已知风险：核心玩家可能认为「剥夺了掌控感」——他们追求的是把已知最优解执行到极致。所以这个改动应该做成可选的额外修饰符，而不是替换原有的 Ascension 数值加压，让两类玩家各取所需。

评分点：满分段的四个要件全齐——保留核心 + 一个具体方案 + 为什么这样设计 + 可验证指标 + 主动承认风险。「反向指标」那一条尤其重要：它证明你考虑的是「改动是否真的改善了体验」，而不只是「指标变好看了」。
这道答案的隐藏优势
第五段里「开局公开禁用清单，所以不违背信息透明原则」这一句，是把自己的方案和游戏的核心设计哲学对齐。这种「改动不破坏原有设计语言」的意识，是产品思维与策划思维的差别，在笔试评分里非常加分。

02答案 B：明日方舟 终末地

推荐理由：它是双核心循环结构，比单循环游戏更能体现你对「系统咬合」的理解；而且作为同赛道重点产品，能自然带出跨平台与质量保障话题——直接对接测试开发岗。

前提：你必须真的玩过
这个答案涉及大量具体机制（连携技触发、战术暂停、产线布局）。没玩过就不要选它——卷面要求写产线布局细节时，没玩过的人根本写不出来。相比之下，杀戮尖塔的机制更通用，容错更高。
题目：选一个你熟悉的游戏，说明核心玩法、优劣，以及你会怎么设计。

① 定位

我选《明日方舟：终末地》，鹰角网络开发，2026 年 1 月全球公测，PC、PS5、移动端跨平台互通。它是一款双核心循环产品——「自动化工业基建 + 4 人小队战术战斗」，面向既想要长线建设成就感、又想要策略战斗的中重度玩家。

核心体验一句话：把一片废土建成一条能自己运转的生产线，再用这条线供养你的战斗队伍。

评分点：准确说出「双核心循环」这个结构判断，比罗列「有建造、有战斗、有抽卡」高一个层级。上线时间与平台信息体现你关注行业动态。

② 核心玩法：两个循环怎么咬合

它的特殊之处在于两个循环并行，且通过资源互相供给：

建设循环：规划电力网络 → 采矿 → 冶炼 → 制造 → 产出装备与消耗品 → 反哺战斗与探索。产线布局受空间限制，游戏鼓励做「输入原料、输出成品」的黑盒产线，而不是简单堆叠单一工序。

战斗循环：4 人编队，普攻积攒能量触发连携技；核心伤害窗口建立在异常状态积累与破防上——物理与法术异常可以叠加并相互反应，同属性叠加收益衰减、跨属性组合收益更高，所以队伍搭配本身就是一道组合题。同时提供战术暂停，让策略思考优先于即时反应。

咬合点：基建产出养成材料 → 队伍强度提升 → 解锁更远的探索区域 → 获得更好的基建蓝图与资源点 → 产线再扩张。两个循环共用同一套资源，所以任何一侧的短板都会卡住另一侧。

评分点：把「双循环」写成有方向的咬合关系，而不是两个并列的功能列表。最后一句是伏笔——它同时是优点的来源，也是缺点的来源，第五段要用到。

③ 优点：两个「解决老问题」的设计

第一，用战斗给基建提供了「需求侧」，解决了建造类游戏目标感缺失的问题。纯工厂类游戏（如《异星工厂》）的经典困境是：产线搭完之后，玩家会问「我造这些是为了什么」。终末地把基建的产出直接接到战斗强度与探索进度上，让每一条产线都有明确的用途。这是结构性的解法，不是加个任务列表就能替代的。

第二，战术暂停把「操作」从胜负变量里剔除了。这是一次针对平台定位的精准适配：产品要同时上 PC、主机和手机，如果战斗依赖即时反应，手机端天然劣势，跨平台体验就不统一。加入战术暂停后，胜负主要由配队与技能循环决定，三端玩家的强度差异被压平了。这是「设计服务于平台策略」的典型案例。

评分点：第一条做了品类对比（异星工厂），第二条把设计和商业/平台策略挂钩。能看出「这个机制为什么在这个产品里必须存在」，是资深玩家的标志。

④ 缺点：一个结构问题，一个质量问题

第一，双循环存在节奏冲突，玩家会在两种节奏间反复被拉扯。这是结构性问题：基建是「慢」的——规划、等待产出、优化布局；战斗是「快」的——进入、连招、结算。当玩家正想专心排产线时被主线推进打断，或正想连续作战时被资源卡住，就会产生「对抗感」而非「协同感」。前面说的「咬合」在资源层面成立，但在时间与注意力层面并不成立——这是双核心循环最难解的地方。

第二，跨平台多支付渠道的质量风险，在公测首日就以事故形式暴露了。2026 年 1 月公测首日，PayPal 渠道出现异常扣款，官方紧急下线该渠道并启动退款。这类问题属于质量保障问题而非设计问题，但它对产品的伤害极大——它动摇的不是体验，而是「敢不敢在你这花钱」的信任。对一个预约量数千万的跨平台产品来说，支付链路的验证成本被严重低估了。

评分点：第一条把「缺点」归因到结构层面（时间与注意力），而不是笼统说「节奏不好」。第二条引用具体事故，并且从「体验伤害」上升到「信任伤害」——对一个测试岗候选人来说，这是最对味的表达。

⑤ 我会怎么设计

我会保留双循环的资源咬合不动，只解决「时间与注意力层面的冲突」：

方案：给两个循环各自独立的进度轨道，只在关键节点强制交汇。

  • 基建侧「异步化」：常规补料交给离线/挂机产出，把在线时间集中留给「产线优化」这类高价值决策——玩家上线是来做决策的，不是来等产出的。
  • 战斗侧「可预约」：把主线战斗段落做成可主动选择进入的，玩家可以先跑起产线、攒够资源，再一次性集中推进剧情。这样两种节奏各自成块，而不是切成碎片互相打断。
  • 交汇点「强制收束」：每个大区域收尾设置一场必须依靠产线产出才能通过的战斗，确保两个循环都被使用，但不强制同时进行。

为什么这样做：双循环的问题不在于「两个都要玩」，而在于「被迫交替玩」。把选择权交给玩家——什么时候切、切多久——就能把「对抗感」转成「规划感」，而这恰好是这两类玩法的共同乐趣所在。

怎么验证有效（四个指标）：

  1. 单次会话内循环切换次数：目标显著下降，说明玩家能成块地玩。
  2. 主线卡点处的流失率：这是核心判据，卡点通常出现在资源不足或战斗过难处。
  3. 交叉参与率：基建深度玩家中参与战斗的比例、战斗玩家中建设产线的比例，防止出现「只造不打」或「只打不造」的两极分化。
  4. 会话时长分布：看是否出现健康的「长会话」，而不是大量 3 分钟碎片会话。

已知风险：「异步化」会削弱基建的即时反馈感——看着产线在自己眼前运转，本身就是乐趣的一部分。所以离线产出应该只覆盖低价值补料，核心的「产线设计与优化」必须留给在线操作，否则基建就退化成了收菜。

评分点：方案分了三条子措施且各自对应一个环节，指标给了四个且包含「防两极分化」的交叉指标，风险也点到了具体机制（即时反馈感）。这一段如果能顺带提一句「跨平台数据一致性是这类改动的测试重点」，对测试岗是额外的加分。
把它转成测试岗优势
答完这道题，可以主动补一句：「如果我从测试角度看这个产品，最大的挑战是跨平台状态一致性——移动端推进日常、PC 端做建造，同一账号的产线状态、战斗进度、资源账本必须强一致，这类跨端数据同步的用例设计比单端复杂得多。」这一句话能把「游戏理解题」变成「岗位匹配度证明」。

03考场怎么选：两者的取舍

结论先给：如果你只有一次机会且不确定自己对终末地的掌握深度，选杀戮尖塔；如果你确实玩透了终末地，并且想主动把话题引向「跨平台质量保障」，选终末地。

维度杀戮尖塔终末地占优
机制清晰度极高，可精确拆到「每回合 3 点能量」高，但系统耦合多，容易说漏杀戮尖塔
阅卷人熟悉度极高，品类定义者较高，但可能比你更熟杀戮尖塔
暴露风险低，机制通用高，产线细节写不清容易翻车杀戮尖塔
体现行业关注一般强，能带出跨平台与质量话题终末地
对接测试岗中等强，跨端一致性、支付链路都是现成素材终末地
适合谁玩过 20 小时以上、想稳拿分真玩透了、想拿高分并体现行业关注看你自己

03.1 · 为什么把杀戮尖塔列为默认推荐

不是因为终末地不好写，而是因为它的容错率更低。原因有三：

  1. 系统耦合度越高，说错的概率越大。终末地的建造、战斗、养成、探索四条线互相咬合，答题时漏掉一条，整段逻辑就断了。而杀戮尖塔只有「地图 + 战斗」两层，不容易漏。
  2. 新游戏的社区共识还没沉淀。老游戏的优缺点已经被大量讨论验证过，你说「高难度流派收敛」，对方大概率认同；新游戏的评价仍在波动，你的判断可能与主流评价不一致，反而暴露理解不够深。
  3. 「双循环」这个答案很亮，但也把标准抬高了。一旦你写了「双循环咬合」，论述就必须深入到「它咬合得好不好、哪里断了」——这需要你对产品有相当深的理解才能接住。
一个折中策略
如果两个都玩过，主体讲杀戮尖塔（稳妥、机制清晰），在结尾用一句话带出终末地：「同类结构上我最近也在关注终末地的双循环设计，它把基建产出接到战斗强度上，这个咬合思路值得研究。」既展示了行业关注度，又不承担展开论述的风险。

04可套用骨架：换任何游戏都能填

把上面两份答案抽象出来，就是一个可复用的填空骨架。考前把它抄三遍，然后拿三个不同的游戏各填一次，这道题就彻底解决了。

text游戏分析题通用骨架
【① 定位】一句话
我选《____》，____（厂商）开发的____（品类）。它面向____（目标用户），
核心体验可以概括为：____（一句话，用「资源/信息/风险 + 交换」这类结构）。

【② 核心循环】拆成闭环，不要罗列功能
行动：玩家每次具体在做什么决策？（____）
反馈：系统立刻给了他什么信息？（____）
成长：这些决策累积成了什么？（____）
再行动：成长之后他去挑战什么？（____）
一句话概括结构：它本质是「____层 + ____层」的双层结构。

【③ 优点】两条，每条要有因果链
第一，____（机制）之所以有效，是因为它把____（变量）从____转移到了____，
   结果是玩家____（心理/行为变化）。
第二，____（机制）与____（产品定位/平台策略）是匹配的，
   对比____（同类产品），它____。

【④ 缺点】两条，必须区分性质
第一，____（现象），这是【设计问题】：根因在____（结构/机制），
   表现为____（玩家行为变化）。
第二，____（现象），这是【资源问题】：根因在____（预算/工期/技术），
   影响的是____（体验/信任/留存）。

【⑤ 我会怎么设计】四件套：保留 + 方案 + 指标 + 风险
保留：核心的____不动，只改____。
方案：____（一句话能说清的具体动作）。
为什么：____（它对齐了原设计的哪个原则）。
指标：①____（直接判据）②____（防作弊判据）③____（反向判据：体验是否被伤害）。
风险：____（会牺牲什么），所以做成____（可选/灰度/分阶段）。

04.1 · 填空时的四个判断标准

位置合格优秀
① 定位说清品类与玩法一句话点出「核心体验」而非「功能构成」
② 循环四个环节都写到能指出它是「双层结构」以及两层如何咬合
③ 优点说得出好在哪能给出「机制 → 心理 → 结果」的因果链，并有横向对比
④ 缺点敢说不好能区分设计问题与资源问题，并给出具体机制证据
⑤ 设计提出一个改进四件套齐全（保留/方案/指标/风险），且指标含反向判据
最后一句提醒
这道题考的不是「你对游戏懂得多」，而是「你能否像开发者一样思考」。所以全文最重要的一个动作是：每说一个现象，都反问自己一句「根因在机制还是资源」。能把这句话说出口的候选人，在这道题上几乎不会失分。
