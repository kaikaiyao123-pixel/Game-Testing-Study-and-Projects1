## 1. 全局前置与契约

### 1.1 环境前置

| 依赖 | 用途 | 缺失时 |
| --- | --- | --- |
| Docker Desktop → `mysql:8.0`(3306) / `redis:7.0-alpine`(6379) | 数据与会话/限流 | 只能跑静态与浏览器验收（见 §6） |
| Spring Boot 3.3.5 / Java 17，8081 | REST API | 同上 |
| 静态前端 3000 (`server/frontend.js`) | 页面与同源注入 | `verify-p2-ui.js` 不可用 |
| Chrome / Edge headless | DOM 探针与截图 | 浏览器类探针不可用 |

- 启动全栈：`bash start-stack.sh`；构建用 java 直接启 Maven Launcher（Git Bash 下 `bin/mvn` 会因路径换算报 ClassNotFound）。
- 常驻 8081 必须后台常驻且 java 前台运行；重建 jar 前先停 8081（fat jar 被 JVM 锁定）。
- 重复跑 P2 验收前清限流键：
  ```bash
  docker exec -i blogg-redis redis-cli EVAL \
    "local k=redis.call('KEYS','ratelimit:*'); for i,v in ipairs(k) do redis.call('DEL',v) end; return #k" 0
  ```

### 1.2 必须继承的既有契约（不得在 P2 改坏）

| 契约 | 内容 |
| --- | --- |
| 统一响应 | `ApiResponse.success(data)` → `{ok:true,data}`；`ErrorCode` 映射 400/401/403/404/409/429/500 |
| 鉴权 | `AuthContextInterceptor.preHandle` **恒放行、只注入 ThreadLocal**；写侧由 `requireLogin()`（401）/ `requireOwner()`（404）把关 |
| 三级权限 | 公开读 = `published` + `public` + `deleted_at_ms IS NULL`；登录读 owner；作者写；**越权统一 404** |
| 分页 | `PageQuery`：`size ≤ 50`，排序白名单 8 项（`created/published/updated/sort_order` × asc/desc）；**`sort()` 是声明式 `列:方向`，拼 SQL 必须用 `orderBy()`**，非法 sort 抛 400 |
| 数据约定 | 主键 UUID `CHAR(36)`、时间 epoch 毫秒 `BIGINT`、软删除 `deleted_at_ms`；迁移只放 `db/migrations/`，**禁止改 `db/init.sql` / V1 / V2** |
| 配置 | 不写 `application.yml`，用 `@Value` 默认值 + `site_config` 表回退 |
| 前端硬约束 | 零外链（禁 `http(s)://` 资源）；用户文本一律 `textContent`；唯一 `innerHTML` 例外是服务端已净化的 `contentHtml`；5 项导航文案逐字固定 |
| 向后兼容 | 原 5 个鉴权 API 响应结构不变；`verify-stack.js` 既有断言不回归 |

## 6. 边界、偏差与环境限制

- **已知偏差**：第三方 Markdown 编辑器未本地化（零外链 + 单一渲染规则），用原生 `<textarea>` + 服务端预览替代；补齐须 vendored + `checkVendor()`。
- **交互边界**：`target_type` 本期只解析 `article`；F3/F4/F5 复用同一组件时再扩展解析。
- **写操作门槛**：发布、编辑、删除、评论、点赞、分享生成、上传、资料修改一律登录；站点开放 ≠ 开放匿名写。
- **越权语义**：统一 404，不返回 403，避免资源存在性泄露。
