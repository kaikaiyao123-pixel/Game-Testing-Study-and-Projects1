## 2. 全局契约（P3 不得改坏）

| 契约 | 内容 |
| --- | --- |
| 响应 / 错误码 | `{ok:true,data}`；400 参数 / 401 未登录 / 403 越权 / **404 越权与不存在统一** / 409 冲突 / 429 限流 |
| 鉴权 | 拦截器恒放行只注入上下文；公开读匿名 200；**所有写操作必须登录**；`owner_id` 一律取自会话，不接受客户端传入 |
| 三级权限 | 公开读 = 已发布/公开/未删除；登录读 owner；作者写；条件同时带 `id + owner_id` |
| 分页 | 页码分页用 `PageQuery`（`size ≤ 50`、排序白名单、**拼 SQL 用 `orderBy()`**）；时间线用 `CursorCodec`（`created_at_ms + id`） |
| 幂等 | 创建类接口支持 `request_id` |
| 零外链 | 新增 JS/CSS/字体/图标一律本地化到 `web/vendor/`，纳入 `selfcheck.js` 扫描；不引 CDN |
| 不引新组件 | Docker Hub 不可达，**不引入 ES / MinIO / 消息队列**；复用 MySQL + Redis；后端保持 `JdbcTemplate` |
| 合规底线（决策 3） | 外链只作**纯文本索引** + 来源标注 + 免责说明；不托管文件本体、不提供播放源、不做自动解析跳转；失效探测低频带退避，只标记不删除 |
| 向后兼容 | 原 5 个鉴权 API 响应结构不变；`verify-stack.js` 既有断言不回归；P2 的 107/44 项不回归 |

**注意**：`verify-stack.js` 的 `userCount===0` 是空库假设；库里有存量账号会得 35/36，需临时「备份 → 清空 → 跑 → 恢复」，最终数据不变。重复跑注册/评论类验收前清 `ratelimit:*`；`verify-p2.js` 与 `verify-p2-ui.js` **之间还要再清一次**（前者会把 `ratelimit:reg:ip:127.0.0.1` 打到阈值 8，导致后者注册 429、token 为空、21 项登录态断言连锁假失败）。降级栈下 `docker exec` 由转发层执行真实 SQL / RESP 命令，判据与标准容器一致。

## 7. 边界、偏差与环境限制

- **不做找回密码（F0-4）**：无短信/邮件网关，不伪造验证码；可预留接口。
- **Cookie 硬化属 P4**：本阶段不动 HttpOnly / CSRF / 令牌轮换 / 生产 CORS。
- **第三方编辑器仍缺**：P2 用原生 `<textarea>` + 服务端预览替代（零外链约束）。若 P3 要补，须完整 vendored 到 `web/vendor/` 并过 `checkVendor()`。
- **影视合规**：只登记纯文本索引；验收必须能自动断言「零托管文件」。
- **标准容器形态受限，但已有可用降级栈**：Docker Desktop Linux engine 在本机无法启动（沙箱策略拦截 `~/.docker/daemon.json` 写入，`wsl.exe` / `reg.exe` 在黑名单），**不能直接跑 `bash start-stack.sh`**。项目外已有零改动既有源码的降级栈：原生 MySQL 9.5（`F:/develop/mysql-9.5.0-winx64/...`，Windows 客户端须加 `--default-character-set=utf8mb4`）+ `%LOCALAPPDATA%\Temp\blogg-redis-lite.js`（零依赖 RESP2/3 替身）+ 既有 jar 跑 8081（`BLOG_SECURITY_REGISTER_LIMIT_IP=8`）+ 3000 前端；`F:\_blogg_shim\` 转发层把 `docker exec` 映射为真实 SQL / RESP 查询（不返回伪造结果），用 `node F:/_blogg_shim/run-probe.js tools/<脚本>.js` 启动依赖容器的探针。P2 阶段已在此环境把 #1–#12 的既有项全部跑绿（0/75/61/70/24/34/36/107/44/33/54），2026-11-12 复核时 3000 / 3306 / 6379 / 8081 均存活且 `/api/health`、`/api/site/config` 返回 200。**因此 P3 的 #5–#12 不必等 Docker**，在降级栈上即可实跑；会话切换后四个常驻进程（mysqld / redis-lite / 8081 / 3000）可能被回收，按 `.workbuddy-ai/memory/2026-11-12.md` 的「原生降级路径」段落重启即可。
- **回标准容器形态**：停掉上述四个进程，用户在非受限终端启动 Docker Desktop 后 `bash start-stack.sh`。
- **P3 验收脚本当前不存在**：#9 / #10 是待建项，不是已有命令；不要在报告里写成「已通过」。
